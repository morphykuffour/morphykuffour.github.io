{%- comment -%} Shadows the theme's own menu_item.html so an entry can carry an `icon:` key naming a file in _includes/icons. The mark goes inside the , which is what gives it the link's colour in all three modes and the whole click target, with the title wrapped so the underline can be held to the word -- run across the whole anchor it passes under the mark and the gap, and reads as a stray dash. Entries without an icon render exactly as upstream, so the nested post list and the plain top-level entries are untouched. It draws two collections now, not one: the homepage menu out of _data/menu.yml, and the elsewhere list on the përi page out of _data/elsewhere.yml. Only the second uses icons; only the first uses post_list. Neither needs to know that, which is why both go through here rather than through a second copy. {%- endcomment -%}
