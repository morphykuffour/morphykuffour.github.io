{%- comment -%} Shadows the theme's own menu_item.html so an entry can carry an `icon:` key naming a file in _includes/icons. The mark goes inside the , which is what gives it the link's colour in all three modes and the whole click target, with the title wrapped so the underline can be held to the word -- run across the whole anchor it passes under the mark and the gap, and reads as a stray dash. Entries without an icon render exactly as upstream, so the nested post list and the plain top-level entries are untouched. An entry can also carry a `cascade:` block -- file, width, height, label -- which is rendered just above its nested entries. That position is the whole reason it is here rather than in the layout: the stack is a float, and a float only moves what follows it in the source, so a stack meant to sit beside a sub-list has to be written immediately before that sub-list. Nothing outside this loop can get between an entry and its own children. {%- endcomment -%}
